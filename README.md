## Projects

### Task 1: BMI Calculator

* **File:** `keerthana_task1_bmi.py`
* **Description:** A GUI-based BMI Calculator developed using Tkinter. It calculates BMI based on height and weight, displays the BMI category, and provides personalized health advice.
* **Features:**

  * User-friendly graphical interface
  * BMI calculation
  * BMI category display
  * Personalized advice
* **Technologies:** Python, Tkinter

### Task 2: Random Password Generator

* **File:** `keerthana_task2_RPG.py`
* **Description:** A Python application that generates random passwords based on user-defined length and complexity.
* **Features:**

  * Custom password length
  * Letters, numbers, and special characters
  * Random password generation
* **Technologies:** Python, Random, String

### Task 3: Weather App

* **File:** `keerthana_task3_BWA.py`
* **Description:** A Python application that displays real-time weather information for a selected city using a weather API.
* **Features:**

  * Search weather by city
  * Display temperature and humidity
  * Show weather conditions
* **Technologies:** Python, API Integration

## How to Run

1. Install Python on your system.
2. Clone this repository:
   `git clone https://github.com/keerthana-2803/OIBSIP.git`
3. Open the project folder in VS Code or PyCharm.
4. Run the required Python file:

   * BMI Calculator: `python keerthana_task1_bmi.py`
   * Random Password Generator: `python keerthana_task2_RPG.py`
   * Weather App: `python keerthana_task3_BWA.py`
5. For the Weather App, configure your API key as required.
